# Unattended resume after reboot (Task Scheduler)

Register once before shutting down; on next **user logon** the task runs
`run_unattended_resume.ps1`, which invokes WSL and `run_unattended_resume.sh`.

## Register (one-liner)

From repo root in PowerShell:

```powershell
.\apu_characterization\register_unattended_task.ps1
```

Unregister:

```powershell
.\apu_characterization\unregister_unattended_task.ps1
```

## Prerequisites

1. **WSL2** with the repo at the same path (e.g. `C:\Users\...\gnn-hls-accel`).
2. **`OPENAI_API_KEY`** as a persistent **user** environment variable (not only
   the current PowerShell session). Required for `apu-gate` FO-01 smoke and full
   v3 replication. Probe-only steps do not use OpenAI.
3. **BLAS thread pin (v3.1+):** drivers set `OPENBLAS_NUM_THREADS=1`,
   `MKL_NUM_THREADS=1`, and `OMP_NUM_THREADS=1` before any NumPy import so
   retrieve matmul CPU books to TOOL, not invisible OpenBLAS workers. Values are
   recorded in `out/setup.json` (`blas_pin`) when `capture_setup` runs.
4. Optional: `$env:APU_REREPPLICATE = "1"` before register if you want a fresh
   replication after the probe suite when the artifact already validates.

## What runs on logon (Mode `Auto`, default)

| Condition | Action |
|-----------|--------|
| v3 artifact validates **and** `out/unattended_probe.done` exists | Exit 0 immediately |
| v3 artifact validates, probes not done | Probe suite (unit tests, tool injection, mass conservation) |
| Replication pid still alive in WSL | Exit 0 (already running) |
| Artifact missing / fails validate | `apu-gate` → start background replication (`run_apu_replicate_unattended.sh`) |
| Replication was interrupted by shutdown (stale pid) | Gate → restart replication |

Other modes: `-Mode Replicate` (replication path only), `-Mode Probe` (probes only).

Replication runs in WSL background (~1 hr). Poll with:

```powershell
wsl make apu-replicate-check
```

## Logs

| File | Contents |
|------|----------|
| `apu_characterization/out/unattended_run.log` | Task Scheduler wrapper + resume decisions |
| `apu_characterization/out/replicate_v3.log` | Full replication stdout/stderr |
| `apu_characterization/out/replicate_v3.state.json` | Unattended replication state |

## Manual dry run (no Task Scheduler)

```powershell
.\apu_characterization\run_unattended_resume.ps1 -Mode Auto
```

Test register syntax only:

```powershell
.\apu_characterization\register_unattended_task.ps1 -TestOnly
```
