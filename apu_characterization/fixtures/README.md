# APU characterization fixtures

Local regenerable fixtures used by the APU characterization harness. Large
binary products stay on disk and out of git history (GIT-3).

## `vectors.npy`

- **What:** NumPy array of shape `(100000, 384)`, `float32`, L2-normalized random
  vectors (seed 42) for cosine-similarity / RAG-matrix work.
- **Origin:** Generated by `generate_fixtures.py` in this directory (committed in
  the APU characterization landing that previously also tracked the binary).
- **Expected SHA-256** (from `fixtures_meta.json`):
  `876e28b7776700dd07d507e0f929f766a21dc8951da491a45008335a84a911b0`
- **Size:** ~146.5 MB — exceeds GitHub's 100 MB blob limit, so it is **not**
  tracked after the GIT-3 history rewrite.

### Regenerate or re-obtain

```bash
# From repo root, with numpy available:
python apu_characterization/fixtures/generate_fixtures.py
# Force rebuild even if a file already exists:
python apu_characterization/fixtures/generate_fixtures.py --force
```

Or copy a preserved copy from the pre-rewrite archive / local backup if you need
the exact historical bytes without regenerating.

## `corpus.txt`

~50 MB text corpus generated by the same script. Remains tracked (under the
50 MB soft ceiling used for GIT-3 verification).
