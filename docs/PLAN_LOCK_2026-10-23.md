## 1. Locked title
"Beyond the KV Cache: A Context Roofline for LLM Agents on Consumer AI PCs" (ISPASS 2027).

## 2. Locked thesis
On consumer AI PCs, an LLM agent's usable context is the minimum of four ceilings: memory tier, model
window, TTFT and decode.
- The memory ceiling is set by the OS-capped GPU-visible tier and the non-KV prefill working set, not by
  the KV cache alone. This bounds what KV compression can buy to (k+a)/a.
- Runtime defaults decide which ceiling binds.

Supporting results:
- the OS formula sets the tier;
- the fleet feasibility frontier;
- design implications;
- DEMO-2 as the negative result on runtime knobs and cost.
